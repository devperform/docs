---
title: Engineer View
description: The per-engineer detail page.
---

Clicking any engineer row in the team dashboard opens their individual detail page. This shows everything in the team view scoped to a single engineer, plus a list of their recent PRs.

## PR history

The detail page lists the engineer's merged PRs for the selected date range, including:

- PR title and repo
- Date merged
- Lines changed
- Cycle time for that PR
- Link to the PR/MR on your code host

This makes it easy to understand what drove a spike or drop in cycle time for a specific period.

## Navigating back

Use the back button or the breadcrumb at the top of the page to return to the team dashboard. The date range is preserved.
